3. Detailed Defect Specifications

BUG_FFC_001: Password maximum length capped at 12 characters
Major Priority P2
ModuleAuthentication (/auth/login)
EnvironmentChrome 120+, Windows 11
Reproducibility100% (Always)
StatusOpen
Steps to Reproduce:
  1. Navigate to https://test.fieldforceconnect.com/auth/login
  2. In the Password input field, enter a strong passphrase longer than 12 characters (e.g., NimapTechSecure@2026!).
  3. Observe the inline validation message under the password box.
Expected Result:
Per NIST SP 800-63B standards, modern applications should support passwords/passphrases up to at least 64 characters to accommodate password managers and high entropy passwords.
Actual Result:
Inline error message triggers: "Password cannot exceed 12 characters". Form submission is blocked.
Suggested Remediation: Update React Hook Form constraint to maxLength: { value: 64, message: "Password cannot exceed 64 characters" } and adjust the backend hashing schema accordingly.
BUG_FFC_002: Absence of Password Visibility Toggle
Moderate Priority P3
ModuleLogin (/auth/login)
EnvironmentCross-Browser
Reproducibility100% (Design Flaw)
StatusOpen
Steps to Reproduce:
  1. Navigate to https://test.fieldforceconnect.com/auth/login
  2. Type a complex password containing mixed case, numbers, and symbols.
  3. Look for an eye icon at the end of the input field to verify typed characters.
Expected Result:
An eye icon toggle should allow users to toggle between type="password" and type="text" to verify inputs before submission.
Actual Result:
No eye visibility toggle icon exists. Passwords remain permanently masked, causing unnecessary failed login attempts.
Suggested Remediation: Include Material-UI InputAdornment with an eye icon button in Login-bCrUzcYN.js.
BUG_FFC_003: 4-Digit OTP input does not support clipboard paste
Moderate Priority P2
ModuleSign with OTP (/auth/otp-verification)
EnvironmentChrome, Windows 11
Reproducibility100%
StatusOpen
Steps to Reproduce:
  1. Initiate OTP login and copy the received 4-digit code (e.g. 4821) to clipboard.
  2. Navigate to /auth/otp-verification.
  3. Focus the first digit box and press Ctrl+V.
Expected Result:
Pasting should distribute the 4 characters across Box 1 ('4'), Box 2 ('8'), Box 3 ('2'), and Box 4 ('1').
Actual Result:
Only the first character ('4') is pasted into Box 1; the remaining digits are discarded. User must manually type each box.
Suggested Remediation: Add an onPaste handler to the OTP input component to extract clipboardData.getData('text') and set all 4 digits simultaneously.
BUG_FFC_004: Sign Up Submit button remains silently disabled
Major Priority P2
ModuleSign Up (/auth/register)
EnvironmentWeb Application
Reproducibility100%
StatusOpen
Steps to Reproduce:
  1. Navigate to https://test.fieldforceconnect.com/auth/register
  2. Enter Company Name, Contact Person Name, Mobile Number, and Email ID.
  3. Leave Timezone or Currency untouched if pre-selection is cleared.
  4. Attempt clicking 'Submit'.
Expected Result:
Form submit button should either remain enabled and highlight missing fields upon clicking, or display a helpful tooltip explaining what is missing.
Actual Result:
Submit button remains grayed out and inactive (disabled={!isValid}) without explaining which field is invalid.
Suggested Remediation: Keep the submit button clickable and invoke trigger() on submit to show red validation borders under invalid fields.
BUG_FFC_005: Case-sensitive Email comparison on Forgot Password
Major Priority P1
ModuleForgot Password (/auth/forget-password)
EnvironmentAll Platforms
Reproducibility100%
StatusOpen
Steps to Reproduce:
  1. Navigate to https://test.fieldforceconnect.com/auth/forget-password
  2. Enter a registered user's email with capital letters (e.g., Tester@FieldForce.com).
  3. Click 'Submit'.
Expected Result:
Email addresses are case-insensitive. System should normalize to lowercase and dispatch password reset OTP.
Actual Result:
API returns 400/404 error and toast alert displays: "Failed to send OTP".
Suggested Remediation: Normalize emailOrMob.trim().toLowerCase() prior to API dispatch.
BUG_FFC_006: Punch In Toast auto-dismiss duration is too brief
Minor Priority P3
ModuleAttendance / Punch In
EnvironmentDashboard
Reproducibility100%
StatusOpen
Steps to Reproduce:
  1. Log in and view the Dashboard.
  2. Click 'Punch In' button and confirm.
  3. Observe the duration of the confirmation popup toast.
Expected Result:
Toast message should remain visible for at least 4-5 seconds and include a manual close button.
Actual Result:
Toast disappears within 1.5 - 2 seconds, causing users on slower devices to miss confirmation.
Suggested Remediation: Set toast configuration duration to duration: 4000.
BUG_FFC_007: Add Customer Mobile field allows non-numeric characters on paste
Major Priority P2
ModuleCustomer Management (/customers)
EnvironmentWeb Application
Reproducibility100%
StatusOpen
Steps to Reproduce:
  1. Navigate to /customers and open 'New Customer'.
  2. Copy string "98765-ABC-12" to clipboard.
  3. Paste into the Mobile Number input field and click 'Submit'.
Expected Result:
Paste handler should strip non-digits or show inline error: "Mobile number must contain digits only".
Actual Result:
Field accepts non-numeric characters, causing form submission to fail with an unhandled server 500 error.
Suggested Remediation: Implement regex input sanitizer e.target.value.replace(/\D/g, '') on paste/change handler.
BUG_FFC_008: Expired session token leads to blank white screen
Major Priority P1
ModuleSession Management
EnvironmentAll Browsers
Reproducibility100%
StatusOpen
Steps to Reproduce:
  1. Log into Dashboard.
  2. Delete currentUser cookie in browser storage to simulate expired session.
  3. Click any sidebar navigation link.
Expected Result:
Application routes user back to /auth/login with session expired notification.
Actual Result:
Application crashes to a blank white screen with console error: "TypeError: Cannot read properties of null (reading 'roles')".
Suggested Remediation: Add Axios HTTP 401 response interceptor and React Error Boundary to catch null session objects.
